The project was designed using an object-oriented structure to separate different responsibilities into individual classes. The `Game` class controls the main game loop and player input, while other classes such as `Player`, `Ship`, `World`, `Shop`, and `Event` each manage a specific part of the game system.
This design improves readability and organization because each class has a clear purpose. It also makes the project easier to extend in the future. For example, new locations, events, or ship upgrades can be added without rewriting the entire game.
One alternative design considered was placing all game logic inside a single `Game` class. While this approach would require fewer files, it would quickly become difficult to manage as the project grows. Separating the systems into multiple classes creates a cleaner and more maintainable design.
The project also makes use of Java built-in classes such as `ArrayList`, `Scanner`, and `Random` to efficiently manage collections, user input, and random events.
